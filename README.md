# EasyTrip

EasyTrip 是一个让旅游爱好者自行定制出游计划的网站。用户可以为不同旅程建立行程项目，按天安排地点，在地图上查看实际路线，并用颜色与图标区分地点标签。

在线体验：[EasyTrip](https://easytrip-travel-planner.yangyixuan0224.workers.dev/)

## 本地预览

在本目录运行：

```bash
python3 server.py
```

打开 [http://127.0.0.1:8000](http://127.0.0.1:8000)。这是无需构建的本地原型；页面入口为 `index.html`，前端交互在 `app.js`，导出模块在 `export.js`，样式在 `style.css`，地点与路线 API 的本地代理在 `server.py`。请通过本地 HTTP 地址打开网页，不要直接使用 `file://`。

## Cloudflare 部署

网站使用 Cloudflare Workers 托管静态页面和 `/api/*` 代理。项目根目录执行：

```bash
npm install
npm run deploy
```

首次部署需要先运行 `npx wrangler login` 登录 Cloudflare。`npm run deploy` 会先将公开页面文件复制到 `dist/`，再使用 `wrangler.jsonc` 发布；Python 本地服务、项目文档和源代码不会作为静态资源上传。部署后可在 Wrangler 输出的 `workers.dev` 地址访问。

本地预览 Cloudflare 版本可运行 `npm run dev:cloudflare`。网站数据仍保存在浏览器的 `localStorage`；`localhost` 与线上域名是两个独立来源，原有本地行程不会自动迁移。地图瓦片、地点搜索和路线仍依赖第三方公共服务，当前线上版本适合个人使用和评审，流量扩大前应换用有服务承诺的服务方。

## 当前功能

- 创建、切换和管理行程项目；已有行程可修改名称、目的地、出发日期和天数，也可删除。删除最后一个项目后会显示新建入口，不会恢复已删内容。每日行程可新增、重命名、调序和删除。
- 按天添加地点，可搜索实际地点，也可点击地图并查询附近地名后直接加入。地点可设置到达时间、标签与备注，之后还能编辑、调整顺序或移除。
- 内置景点、餐厅、咖啡、住宿四种标签；用户可为当前行程创建、修改和删除标签，从 12 个图标和 10 种颜色中选择。删除已使用的标签时，其地点会改用另一标签。标签筛选只改变卡片与地图标记的可见性，不改变路线计算。地图角落最多直接显示 3 个无背景图标；超过 3 个时显示前 2 个及 `+N`，悬停展开，点击固定。
- 每两个地点之间可用伸缩胶囊独立选择步行、骑行或驾车，选择时有文字和图标过渡动画。地图按出行方式给路径和图标着色，仅显示方式图标与公里数；行程列表显示各段距离与时间。
- 地图顶部的窄搜索框位于地图标题和缩放按钮之间。中文界面使用宋体，西文与数字使用 Arial；每日行程中的地点信息使用更大的字号。
- 可导出可打印的 HTML 行程大纲，包含每日地点、标签图标、备注、逐段交通图标、道路距离和预计时间；也可导出覆盖整个旅程范围的 SVG 路线地图。路线服务不可用时，大纲会明确标注距离暂不可用。地图导出使用独立矢量图层，不包含在线地图瓦片。
- 自动保存在当前浏览器的 `localStorage`。首次使用新版时，旧版京都草稿会迁移到 EasyTrip 项目中。
- 地点或路线服务失败时保留已有行程，并明确提示状态。

## 当前边界

这是本地单人原型，没有账号、跨设备同步或公开分享。示例地点中部分使用预置坐标；新加入的搜索地点取自 Photon，地图点选保留用户点击的坐标。行程时间仅含路途耗时，不含游览、排队、用餐或停车时间。地图与地点、路线服务为公共演示实例，可能限流或不可用；正式上线前需要更换成可承载网站流量的服务并完善后端保存。导出地图的背景是示意网格；当某天的路线服务失败时，该天连接线会以虚线表示地点相对位置。
